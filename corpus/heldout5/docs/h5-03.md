# Data Pipeline Setup — Northfield Veterinary Group

Scope for a nightly job that pulls appointment records from the clinic system, cleans them and loads a reporting database.

## What gets built

| # | Item | Done when |
|---|------|-----------|
| 1 | Extract script | Pulls all appointments for the previous day; row count matches the source export to within 0 rows |
| 2 | Cleaning step | Duplicate and blank-phone rows removed; rules listed in the appendix |
| 3 | Load step | Writes to the reporting database before 05:00 local time on 28 of 30 test nights |
| 4 | Runbook | A 2-page PDF covering restart and failure alerts |

## Review

Northfield reviews each deliverable within 7 calendar days of the hand-over note. Silence after day 7 counts as acceptance of that item.

## Changes

Two small adjustments to the cleaning rules are included. After that, a change is estimated in hours, priced at 70 USD per hour, and agreed by email before it starts.
