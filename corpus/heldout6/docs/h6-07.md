# Statement of Work: Customer Support Chatbot

**Supplier:** Halden Analytics
**Customer:** Rowan & Pike Outfitters

## 1. Objective

Build a chatbot that answers the 40 most common order and returns questions listed in Appendix 1, using the retailer's help-centre articles.

## 2. Deliverables

- Retrieval pipeline over the 120 help-centre articles
- Chat widget embedded on the returns page
- A test sheet of 100 sample questions; target is that at least 90 of them get an answer judged correct by two reviewers from the Customer's team

## 3. Model usage

The language model API is billed by the provider on a per-token basis. The Customer creates the API account and pays the usage bill directly. Halden Analytics estimates 20 to 60 USD per month at expected traffic.

One round of wording changes to bot answers is included. Further changes are quoted separately at 85 USD per hour before work starts.
