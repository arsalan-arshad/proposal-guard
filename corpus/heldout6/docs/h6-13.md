# SOW: Online Store Rebuild for Quick Fix Bikes

Quick Fix Bikes is a repair shop in Rotterdam. This SOW covers moving its store to a new platform.

| Phase | What happens | Owner | Cost carrier |
|---|---|---|---|
| 1 | Product import (about 400 SKUs) | Studio | Studio |
| 2 | Theme set-up | Studio | Client buys the theme licence |
| 3 | Payment gateway connection | Studio | Client (per transaction fees) |
| 4 | Shipping label app | Client chooses | Client |
| 5 | Launch | Studio | n/a |

Fee: EUR 3,900. Phase 1 to 3 invoiced at the end of phase 3, the rest at launch.

The Studio will work with the shop until things look good.

There will be a final check by the Client before launch. Revisions to the theme are handled in a friendly way.
