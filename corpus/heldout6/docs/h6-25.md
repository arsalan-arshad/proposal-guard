# Legal-Tech Intake Form: Project Terms

**Developer:** Oyelaran Software
**Client:** Whitcombe & Rao LLP

## Deliverables

| ID | Deliverable | Acceptance test |
|----|-------------|-----------------|
| D1 | Client intake web form (9 questions) | all 9 fields validate; submission appears in the firm's case system |
| D2 | Conflict-check export | CSV with 7 named columns, generated in under 30 seconds |
| D3 | Admin screen to edit question text | admin can change text without a code release |

## Costs

| Item | Who pays | Amount |
|------|----------|--------|
| Case system API access | Client | per their vendor contract |
| E-signature service | Client | about 15 USD per user per month |
| Hosting of the form | Developer for the first 6 months, then Client | included to month 6 |
| Security certificate | Developer | included |

## Process

Client reviews each deliverable against its acceptance test within 6 working days of delivery. If the Client does not reply in that period, the deliverable is accepted for invoicing purposes.

Included: 1 round of text corrections per deliverable. Additional rounds: GBP 90 per hour with a written estimate first.

Fee: GBP 8,800, in three instalments tied to D1, D2 and D3.
