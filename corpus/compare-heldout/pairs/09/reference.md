Brief: moving our reporting stack to the cloud

We are Meridian Pet Supply and our order reports run on a single old server in the back office. It is slow and the person who set it up left last year. We want to move the reporting database and the nightly jobs to Google Cloud and add basic monitoring.

In scope
- Move the PostgreSQL database and the nightly export scripts
- Set up the same jobs on managed services
- Backups with a restore test
- Alerts by email when a job fails

We would like the move done with no more than one night of downtime. We do not need any changes to the shop itself, and no SSL certificate work is needed because the reporting tool is internal only.

Access: we will give you a project in our Google Cloud organisation and a read-only user on the old server.

Timeline: the cut-over should be completed within 5 weeks from the start date.

Sign-off: our CTO, Birgit, approves the cut-over plan and the final handover. We have not agreed how quickly she can do this, because it depends on her travel.

Invoices are paid within 30 days.
