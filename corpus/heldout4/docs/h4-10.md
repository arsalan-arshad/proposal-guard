# SOW: Contract Review Assistant (internal prototype)

**Client:** Aldermoor Legal Services
**Supplier:** Sunil Verma

## 1. Description of work

The Supplier will build a prototype web tool that lets paralegals upload a PDF and see a list of clauses grouped by type (indemnity, termination, governing law, payment terms). The tool will use a hosted language model API to label clauses. Accuracy is not guaranteed; the prototype shows the labelled text so a person can check it.
