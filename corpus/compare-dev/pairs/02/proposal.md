Proposal for Harbourline Utilities Cooperative
Field Inspection Mobile Application

Summary
We will build an offline-first inspection app for iOS and Android using React Native, with a sync service connected to your inventory database.

Deliverables
1. Mobile app with offline capture, photo attachment and GPS tagging
2. Sync service running in your AWS account
3. Admin guide and a one-day onsite training session
4. Source code and build instructions

Timeline
We will complete the build and deliver the final app in 8 weeks from the signed agreement. A first working build for field testing is available at week 4.

Acceptance
Your operations manager reviews each release candidate within 5 business days of delivery. A release candidate with no written response after that period is treated as accepted.

Payment
Milestone invoices are payable within 30 days.

Changes
Requests beyond the agreed feature list are written up as change requests with an estimate, and start only after you approve the estimate.

Team
One project lead, two mobile engineers and one QA engineer.
