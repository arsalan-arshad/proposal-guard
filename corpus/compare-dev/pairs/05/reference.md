Data project: tidy and map our customer addresses

We are a small furniture retailer with about 40,000 customer records collected over ten years. Addresses are a mess: typos, missing postcodes, mixed formats.

What we want
- Clean and standardise all addresses
- Geocode each cleaned address with the Google Maps API so we can plot customers on a map
- Group customers by delivery zone and produce a summary sheet for each zone
- Use the OpenAI API to categorise the free-text "delivery notes" column into a handful of types (gate code, leave with neighbour, call first, and so on)
- A short written report on what you found and how you did it

Data will arrive as a CSV export. The data is confidential, so please do not share it with anyone.

We would like the first cleaned file in about a week and everything wrapped up in 3 weeks. Payment is within 14 days after we receive your invoice.

Please include examples of data cleaning you have done and the tools you normally use.
