# Project Proposal: AI Recruiting Assistant

## Summary
We will build a web app that screens CVs with an LLM and ranks candidates. The app will be easy to use and will integrate with your existing tools.

## Delivery
Development takes about 8 weeks in two phases. Phase 1 is a working prototype. Phase 2 adds reporting, user roles and so on.
You will test each phase and tell us what to change. We will make the changes needed and then you sign off.

## Infrastructure
The app runs on Railway. Model calls go to the Anthropic API. Candidate emails are sent via SendGrid.

## Fees
Fixed price of 18,000 USD, invoiced 50% at start and 50% on sign-off of Phase 2.
