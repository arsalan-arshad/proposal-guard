# Statement of Work — Mobile App

## 1. Objective
We will deliver a cross-platform mobile app for a regional gym chain. The app will be user-friendly and will support class booking, membership payments, and so on.

## 2. Technology
The backend will run on Azure. Push notifications are sent through Firebase. Payments use Stripe.

## 3. Timeline and acceptance
The project runs for about 10 weeks. Each milestone is delivered for client approval. Payment for each milestone is due on approval.

## 4. Changes
We offer revisions as needed during development. Any extra features will be discussed.

## 5. Support
After launch we provide support for bugs and small tweaks.
